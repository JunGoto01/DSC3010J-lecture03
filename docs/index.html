BEFORE THE CODE

      
回帰とは、ばらついた人々を「一本の共通規則」で要約する方法

      
一つの点が一人を表します。人は同じではないので点はばらつきます。回帰はばらつきを消す魔法ではなく、全体に見られる大まかな関係を予測規則にまとめる方法です。


      

        

          
1　普通の回帰：点の真ん中に直線を通す

          
          
予測値 = a + b × x

          
aは出発点、bは手がかりxが変わったときに予測がどれだけ動くかです。Rが点全体に合う値を探します。

        


        

          
2　答えが0/1：S字で「確率」に収める

          
          

            z = b0 + b1 × 等級 + b2 × 性別
            p = 1 ÷ (1 + e−z)
          

          
まず情報を一つの点数zへまとめ、S字で0〜1の確率pへ変えます。式の暗記・手計算・係数の解釈は今日は不要です。

        

      


      

        
乗客の手がかり2等・female
→
        
Rが重みを付ける点数 z
→
        
S字で0〜1へ確率 p = 0.72
→
        
0.5以上予測 1

      


      

        
glm()
trainの正解に合う重みを探し、規則を学ぶ。
→
        
predict()
同じ規則でchallengeの確率を出す。
→
        
ifelse()
0.5を境に、提出用の0/1へ変える。

      


      
ロジスティック回帰＝0/1用の回帰普通の直線は0未満や1より大きい値を出せます。S字を使うロジスティック回帰なら、予測を必ず0〜1の確率に収められます。
