WHAT IS A DATA COMPETITION?

データコンペティションは、同じ予測問題に答えを提出し、同じ物差しで比べる活動

主催者が「何を予測するか」「どのデータを使うか」「どう採点するか」を決めます。参加者はデータから予測方法を考え、正解を見ずに答案を提出します。採点結果はスコアやランキングとして返ります。順位だけでなく、問いから評価までを一周できることが、データ分析の練習になります。

1　主催者から受け取る問題とデータ

答えが分かる例を見て、何を予測するかを確認する

→
2　参加者が行う分析と予測

データの特徴を調べ、未知の答えを予測する規則を作る

→
3　Webサイトへ送る予測を提出

正解を見ることなく、一人ずつの予測答案を送る

→
4　同じ基準で返るスコアと順位

隠してある正解と照合され、結果を改善する手がかりが返る

この授業用ページが、Kaggleの役割を小さく再現します

REGRESSION → LOGISTIC REGRESSION

回帰は、全員に使う一つの予測規則を作る

一人ずつ別の規則を暗記するのではなく、データ全体に見られる関係を少数の数字にまとめます。その数字を係数と呼びます。

普通の回帰：数値を直線で予測する

ŷ = a + b × x

aは直線の出発点、bは傾きです。答えが試験点などの連続した数値なら、直線上の値をそのまま予測に使えます。

ロジスティック回帰：0/1を確率で予測する

z = b0 + b1 × 等級 + b2 × malep = 1 ÷ (1 + e−z)

式の中ではfemaleをmale = 0、maleをmale = 1として数値に直します。最初の式で手がかりを点数zへまとめ、S字の式で0〜1の確率pへ変えます。どんな点数でも確率は0未満や1より大きくなりません。

Rはtrainから、どのように係数を決めるのか

  1. 1仮の係数を置く

    等級と性別へ、まず仮の重みを付けます。

  2. 2630人の確率を出す

    同じ式をtrainの各行へ使います。

  3. 3既知の0/1と比べる

    正解1には高い確率、正解0には低い確率が望ましいと評価します。

  4. 4係数を少し直す

    630人全体への当てはまりがよくなる方向へ調整します。

  5. 5一つの規則として保存

    調整を繰り返し、完成した係数一式をmodelへ保存します。

trainの行を丸暗記するのではありません630個の答えを、全員へ共通に使える少数の係数へ圧縮します。challengeへは、この完成した係数を変えずに使います。
