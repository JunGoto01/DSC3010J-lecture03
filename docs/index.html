データコンペティションは、同じ予測問題に答えを提出し、同じ物差しで比べる活動

REGRESSION → LOGISTIC REGRESSION

回帰は、全員に使う一つの予測規則を作る

一人ずつ別の規則を暗記するのではなく、データ全体に見られる関係を少数の数字にまとめます。その数字を係数と呼びます。ここでは「各手がかりが点数をどれだけ動かすかを表す重み」と同じ意味です。

普通の回帰：数値を直線で予測する

ŷ = a + b × x

ŷは予測する試験点、aは直線の出発点、bは勉強時間が1増えたときの傾きです。答えが点数のように連続した数値なら、直線上の値をそのまま予測に使えます。

ロジスティック回帰：0/1を確率で予測する

z = b0 + b1 × 等級 + b2 × malep = 1 ÷ (1 + e−z)

生存0/1へ普通の直線をそのまま使うと、予測が0未満や1より大きくなることがあります。そこで、まず手がかりを点数zへまとめ、S字の式で0〜1の確率pへ変えます。式のeはS字を作るための定数で、値を覚えたり手計算したりする必要はありません。femaleはmale = 0、maleはmale = 1として扱います。

なぜ0/1の問題には、S字の変換が必要なのか

普通の直線−0.2　←　0　…　1　→　1.3

直線はどこまでも伸びるため、「確率−0.2」や「確率1.3」のような解釈できない値を出せます。

ロジスティック回帰のS字0　≤　確率 p　≤　1

どのような点数zでも0から1へ収められるため、生存しそうな程度を確率として読めます。

重み付き点数の式を、日常の言葉で読む

z = b0 + b1 × Pclass + b2 × male

b₀出発点

どの乗客にも共通する基準の点数です。

b₁ × Pclass等級の分だけ動かす

等級の数値に、trainから学ぶ重みを掛けます。掛け算は、この手がかりが点数をどれだけ動かすかを表します。

b₂ × maleカテゴリーの差を加える

femaleなら0、maleなら1です。0を掛ければ差は加わらず、1を掛ければ重みが一回分加わります。

b₀, b₁, b₂全員に同じ重み

Rがtrainから決め、すべての乗客へ同じ値を使います。手で計算する必要はありません。

trainの一行が、規則を直す方向を教える
